🧪 Mail9ja Form Test (Local)

Testing embed.js and embed.css from local files before pushing to production

📝 Instructions:
  1. To test a production form: Add ?token=YOUR_FORM_TOKEN to the URL
  2. Or set token directly: Edit line 74 and set data-form-token="YOUR_FORM_TOKEN"
  3. Edit scripts/embed.js or scripts/embed.css
  4. Copy to public/ folder: cp scripts/embed.js public/embed.js
  5. Refresh this page to see your changes
  6. Test thoroughly before pushing to production

💡 Tip: You can test any production form locally by using its form token!
