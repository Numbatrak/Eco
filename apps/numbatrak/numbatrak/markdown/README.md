# Mail9ja

A modern SaaS Operations Dashboard built with React. This project provides a comprehensive interface for managing and monitoring SaaS operations.

## Running the code

Run `npm i` or `pnpm i` to install the dependencies.

Run `npm run dev` or `pnpm dev` to start the development server.

## Database & Automation

This project uses GitHub Actions for database backups and keep-alives.
[View the Actions & Database Restore Guide here](./ACTIONS.md).
